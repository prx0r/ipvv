## bodh-p01 (2-10)
[and]-citiḥ svatantrā viśvasya hetur ity abhidhīyate / svātantryarūpā jñātā ca siddhīr vā saṃprayacchate sā svabhittau svecchayaiva viśvasyonmīlanāya ca / nānānurūpavaicitryād grāhyagrāhakabhedataḥ viśvasya tasya vaicitryaṃ grāhyabhedena saṃsthitam / nānāvaicitryayogena cottamādhamasaṅkhyayā citisaṅkocanāc cittaṃ cetano 'pi maheśvaraḥ / vaṭadhanikāvat tatra viśvarūpaṃ ca tad viduḥ caitanyam ātmano rūpaṃ śuddham atyantanirmalam / tad eva niyamāsaktaṃ cittaṃ cid abhidhīyate arthonmukhatayā saṃvic citte viśrāntim āgatā / saṅkocātmapradhānatvāc citiś cittaṃ vidur budhāḥ māyāpramātā cidrūpas tanmayatvena dehinām / vartate viṣayāsaktaḥ sadvivekavivarjitaḥ sadaikaḥ pratithaś cittaṃ kalāsattvaguṇādibhiḥ / saptapramatṛkatvena ṣaṭtriṃśattattvasaṅkhyayā ekaḥ sarvagataḥ śuddhaḥ sambodhātmā maheśvaraḥ / saivāhantāparijñānān muktiḥ karatale sthitā

## bodh-p02 (11-20)
[and]-pramātṛsaptakatvena ṣaṭtriṃśattattvasaṅkhyayā / bhāvitaḥ sa maheśāno mokṣalakṣmīḥ pravartate tadbhūmikā darśanādyās sarvā eva na saṃśayaḥ / bhūmikāḥ kṛtrimā yadvan naṭo gṛhṇāti svecchayā cidānandasamullāsollasitātmā virājate / cidvatsvaśaktisaṅkocāt saṃsāre malināyate apūrṇo 'smīti vividhair malaiḥ sa malinīkṛtaḥ / māyīyāṇavakārmākhyair vyāpako 'pi jagadvibhuḥ vyāpī yadvan mahādevaḥ kroti pañcakṛtyatām / tadvad evāyam ātmāpi kurute śaktimohitaḥ śakto vikāsāc chaktīśo gīyate tattvavādibhiḥ / saṅkocanāt saṅkocitaḥ saṃsārīty abhidhīyate māyā rūpaṃ hi yat kiṃcid ālokayitum udyatā / sādhyasṛṣṭiṃ vijānīyād anyā śaktiḥ sthitir matā saṃhārāt saṃhṛtā devī cidaikye 'nugraho mataḥ / tadekasārāprathanāt tirodhānābhidhīyate itthaṃ sadā saṃnihitaḥ pañcavāhavidhiḥ kramāt / jñātaś cintāmaṇir asāv ajñānāt kāṣṭaloṣṭavat

## bodh-p03 (21-29)
[and]-sadvimarśabalenaivaṃ nityaṃ yaḥ pariśīlate / sa muktaḥ sarvabandhebhyo nityānandamayo bhavet cidvahnir grasate so 'yaṃ suprabuddho 'sty asau yadā / tadāsau vimalo jñeyaś cidvahniḥ sarvabhakṣakaḥ etadbalena saṃyukto yogī nirvāṇalakṣaṇaḥ / padaṃ prāpnoti vimalaṃ so 'cirān nātra saṃśayaḥ cidvahnir balalābhe 'pi viśvam ābhāti cinmayam / svānandāmṛtakallolam etad ucchalitaṃ bahiḥ tad eva śyānatāṃ yātaṃ bhāvarūpair vibhāvyate / svātmā maheśvaro devaḥ krīḍate parameśvaraḥ iti yaḥ satataṃ vetti sa mukto mocayaty api / sattvavrātaṃ kṣaṇenaiva ghorāt saṃsārabandhanāt yaḥ kaścit ānandabalaḥ sa svarūpapadasthitaḥ / iti yasya samullāsollāsitodayaśālinaḥ tasya svarūpaniṣṭhasya vyutthāne 'pi tad arthyate / etat prayatnasāmārthyāj janair evādhigamyate madhyadhāmavikāsāc ca cidānandāt prakāśate / tatprakāśād divyadṛṣṭir jñānarūpā vibhāvyate
