## ajad-p01-v06 — argument map

**Speaker.** objector (pāda ab), answered by Utpaladeva (pāda cd)

**Question.** Does function (arthakriyā) distinguish existent from nonexistent?

**Premises.**
- The existent alone works its function (arthakriyāṃ kuryāt); the other does not — so how undistinguished?
- And yet the thing, in its own self (nijātmani), stays without mark.
- Vṛ names the move: the objection (ākṣepa), then the reply — function runs on knowers (tattatpramātradhīnatayā), never self-seated.

**Inference.** Function marks the scene, not the self: the objection states itself and is contained within the reply.
