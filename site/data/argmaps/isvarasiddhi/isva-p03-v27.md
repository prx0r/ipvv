## isva-p03-v27 — argument map

**Speaker.** Utpaladeva (siddhāntin)

**Question.** What is conceived?

**Premises.**
- If (cet) puruṣārtha-natured (puruṣārthasvabhāvatvaṃ) in all function-acts (samastārthakriyāsu).
- By pradhāna (pradhānasya) it is conceived (upakalpyate) as efficient (nimittakāraṇatvena).

**Inference.** Conditional close: puruṣārtha-natured acts conceived efficient by pradhāna.
