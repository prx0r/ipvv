## isva-p04-v33 — argument map

**Speaker.** Utpaladeva (siddhāntin)

**Question.** If from potter-helping?

**Premises.**
- Making (racanā) by rule (niyamena) would be (syāt) wondrous (vicitrā), kind-formed (jātirūpiṇī).
- If (cet) from potter-helping-mereness (kulālasahakāritvamātrāt) a pot is born (jāyate ghaṭaḥ).

**Inference.** Conditional: rule-wondrous making — if mere potter-help bore pots.
