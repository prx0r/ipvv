## isva-p06-v51 — argument map

**Speaker.** Utpaladeva (siddhāntin)

**Question.** Mercy-acts — passionless?

**Premises.**
- There'd be acts even of spirit-distinction-knowers, from compassion (syur jñātapuṃvivekānāṃ karmāṇy api kṛpāditaḥ).
- If not from passion — thus mokṣa from passion's exhaustion (na rāgāt tāni ced evaṃ mokṣo rāgakṣayād bhavet).

**Inference.** Compassion smuggles passion back; the view becomes passion-exhaustion doctrine.
