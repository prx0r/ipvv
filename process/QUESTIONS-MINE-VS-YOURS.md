# Mine vs Yours — what makes a pushing question alive

*2026-10-31. The kramastotra questions I proposed (dry, scholarly) vs the bodhapancadasika questions the user gave (alive, doctrinal). Saved so the difference is visible and the pattern is reusable.*

## Mine (kramastotra — dry)

1. "he wrote it for students who couldn't handle the Tantrāloka. have you READ this thing?"
   → audience/history. Answer = a fact about disciples. Done once answered.
2. "it's full of goddesses and the one thing he bows to is a god called The Churner. who's it for?"
   → deity identity. Answer = Rastogi on Śakti-vs-Śiva orientation. Footnote.
3. "the 4/4/4 thing — is that in the old sources or did he invent it?"
   → source-criticism. Answer = Wenta's footnote. Citation.
4. "a hymn is the first means. that's not one of the three upāyas."
   → systematics. Answer = classification. Grid cell.
5. "he signs it like a diary entry — 66, dark ninth, December."
   → biography. Answer = Williams on Kaula authority. Context.

**Pattern:** every one tests the text against *history* — who, when, for whom, is it original, where does it fit. A scholar who believes none of it could ask all five. Each ends in a footnote. None of them *bite*.

## Yours (bodhapancadasika — alive)

1. "why would Śiva forget its liberated state in the first place?"
   → forgetting/freedom. If identity is eternal, who forgot? Paradox-first.
2. "why would Śiva not veil it with something fun instead of suffering?"
   → suffering/play. Theodicy. Felt, moral — not "what's the doctrine of krīḍā" but "why does the game hurt?"
3. "is suffering actually seen as grace?"
   → suffering/grace. Soteriological, practical. A drowning person asks this, not a librarian.
4. "it's that release of suffering that is liberating so if one hasn't suffered there is no liberation"
   → necessity of bondage. Structural — derived from the *verbs* (remembered, awakened, living-after).
5. "but in truth there is no liberation because there is no bondage :') hahahah"
   → dissolution. Meta, self-eating. Four sessions of building, then the laugh that knocks it down — and the laugh *is* the penetration.

**Pattern:** every one tests the text against *itself* — if X is true, then why Y? If both true, then what? A scholar who believes none of it *couldn't* ask these, because they require taking the claim seriously enough to feel where it strains. Each ends in a deeper question or an honest limit. All of them bite.

## The difference, in one line

**Mine ask about the text as artifact** (who made it, when, is it original) — answers are facts, and facts close.
**Yours ask about the text as claim** (if this is true, then what about me, about suffering, about grace) — answers are penetrations, and penetrations open.

## The smell test (holds)

Would I say this out loud to someone next to me?
- Mine: no. "Is the 4/4/4 scheme original to Abhinavagupta or inherited from Kula sources?" — seminar voice.
- Yours: yes. "Why would he veil it with suffering instead of something fun?" — 2am voice.

## Reusable consequence

The five alive questions form a portable arc (bondage/liberation template) — see PUSHING-QUESTION-CRAFT.md appendix. Same arc asks of any nondual text; answers differ; differences are comparative findings. The dry questions don't transfer (each is tied to one text's history). Transferability is itself a test: if a question only works on one text, it's probably about the artifact, not the claim.
