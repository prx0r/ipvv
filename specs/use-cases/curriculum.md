# Curriculum — essays + passages + cruxes + scholars as guided stages

## Inputs
- 22 essays in 3 groups (comparative / core proofs / extensions) + review badges.
- 49 IPVV passages (recite + read), pushing cruxes (Q1–Q10 gems), 36 scholars.
- The survey's 8-stage map (Somānanda → Utpaladeva → Abhinavagupta → PTv →
  Kṣemarāja → Krama → poetry → consciousness).

## Behavior
- Each stage: essay (thesis) + source passages (evidence) + crux probes (pressure-test)
  + scholars (read alongside) + recitation (voice).
- Review badge = syllabus trust signal (reviewed vs working).
- Progress = stages completed, not pages viewed.

## Phases
1. Static stage pages linking existing sections (no new data).
2. Progress tracking (needs accounts backend — shares workbench auth).
