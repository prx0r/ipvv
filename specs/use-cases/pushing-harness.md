# Pushing harness — autonomous agents that can't hallucinate

*Cognition (unlimited, untrusted) → deterministic gates (no LLM) → truth (canonical) → grants (authority).
Workers propose; validators judge; QP commits. (agentcomfinal constitution, applied.)*

## Roles (5 workers, each a versioned system prompt)

| Role | Proposes | Cannot |
|---|---|---|
| Questioner | questions + branches (9 DNA moves + 6 chain shapes + voice exemplars) | answer, judge, promote |
| Solver (Pass A) | session .md + graph records (MACHINE_DRAFT) | assign status, quote without source bytes present |
| Prosecutor (Pass B) | objections only — cannot improve, only destroy | construct, soften, promote |
| Prover (Pass C) | provenance map + receipt (mostly deterministic) | write new claims |
| Essayist (later) | essay draft + traceability links at derived strengths | overclaim, use BLOCKED English, skip falsifiers |

## Anti-hallucination (structural, not instructed)

1. **Agents reference, never mint** (agentcomfinal B2): ids/receipts derived by pipeline from content + gates. Writing "ESTABLISHED" in prose changes nothing.
2. **Quotes byte-checked** (L0 evidence-declared + quote gate): fabricated quote → gate FAIL → INVALIDATED receipt attributed to that model+RUN. Hallucination becomes measured model behavior, not corpus corruption.
3. **DONE requires receipts** (T1): no receipt chain = no advance, no matter what the agent asserts.
4. **Status derived, not claimed**: STATED ⟸ byte-match; ESTABLISHED ⟸ premises + zero surviving objections; strength = proof_level from gate outputs + objection count.

## Loop (per UNASKED cell)

TASK (acceptance: session + gates + receipt) → Questioner proposes → Solver constructs → gates → Prosecutor destroys → surviving-objection count → status derived → TransitionReceipt → human reviews → PROMOTE grant or kill → graph grows → re-embed.

## What to lift vs write

- Lift: gate catalog shape (L0–L4), A-TASK pattern, constitution sentence, test patterns (`test_no_qp_fabrication`, `test_proven_requires_receipt`).
- Write: 5 role prompts (versioned, hashed), pushing gate battery, extractor + verifier, trajectory bank (DNA versions × shapes, gems-per-token).
