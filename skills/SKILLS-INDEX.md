# SKILLS-INDEX — which skill, in what order (ipvv skills, canon)

*Read `AGENTS.md` first for laws. This index organises the craft
skills for the parable→seal→art chain. Full method + mistakes:
`translation-work/THE-WHOLE-CRAFT.md`.*

## The writing chain (order matters)
1. **`literal/`** — exact English from Sanskrit (STE-80, Sanskrit-
   first, no-metaphor, resolve-tiers). Use for LITERAL lane work.
   No parable is blocked on it (owner 2026-11-04) but it feeds
   precision.
2. **`allegory/`** — THE PARABLE skill. Modes: parable (default),
   myth, eli5. Laws: plain-words-inside, map-hinge, limit, rasa,
   tortoise-and-hare bar, third-person text (voices separate),
   worked example = the spider (param s04 — the 9.5 benchmark).
3. **`p1-seal/`** — THE P1/SEAL skill. Northstar verbatim +
   flow: parable → seal (zone table double-anchored, colour
   cipher, composition laws, base stage-match + seed, prompt =
   seal-text-only with implicit Solis style, hermetic clues,
   anti-mistake checklist) + the taste-law rounds (nature-first,
   doorway titles, animals-encode-technicals, one-line test).
