## Flow (per work, shortest → longest, canonical parable per work)

1. **P0 — the parable.** Read ALL layers of the song/passage first:
   Sanskrit cite → argmap (clearest explanation) → L4 couplets (the
   music + authorized imagery) → C1 essence + rasa → L2. NO separate
   literal pass required (owner, 2026-11-04) — the canonical parable
   falls out of the work directly. Laws from `allegory` still bind:
   ordinary words inside, one essence-scale story, ≤2 characters or
   pure image, one turn, end on the turn, no moral inside, tortoise-
   and-hare bar (retellable from memory), map=hinge, limit stated,
   rasa named. Target **45–90 seconds spoken** (~110–220 words) —
   short enough to voice in one breath of a short.
2. **Seal reread.** Re-read the same layers asking one question:
   what single vertical/square image CONTAINS this story as an
   argument? Hermetic/emblem method (McLean, in PARABLEVIDEO
   apparatus): integrated image, geometry = meaning, relations not
   dictionaries, read from within the text only.
3. **P1 document** (`<work>/P1-<song>-SEAL.md`) must contain, with
   full reasoning:
   - the seal statement (one sentence: what the image IS);
   - **zone/element table**: element → verse → C1 essence idx →
     argmap step → rasa job (every element double-anchored —
     if it can't cite verse AND essence, cut it);
   - **colour cipher** from C1 rasa (colour → meaning → anchor);
   - correspondence axis (inner/outer light etc. — the work's thesis);
   - composition laws (zones connected, ONE subject, trap rendered
     as knot/tangle if parable has one, no roundel/template talk);
   - **Solis base choice**: stage-match per `SOLIS-REFS.md` (plate's
     operation = parable's arc), structure (bordered page), quality,
     spent-log check → record plate + why + fresh seed;
   - **the image prompt** (seal text ONLY — vivid, complete, mandala-
     like; reference carries style implicitly; material vocabulary
     allowed: vellum ground, burnished raised gold over red bole,
     lapis/vermilion, pale before dark, black outline, white
     highlight, shell-gold accents — never "make it Solis");
   - **anti-mistake checklist** run (double-anchor, one-subject,
     zones, colour cipher, geometry/actions, gold hierarchy,
     no text/letters, new base, LESS-is-better) — boxes ticked.
4. **Queue, don't render.** Save P1 + parable; renders happen only
   after owner confirmation, in registry batch order, lands in R2
   `parables/` with seed + P1 path logged. Renderer when approved:
   fal flux-pro/kontext ($0.04, key /root/.fal-key) with the chosen
   EXACT base + prompt; CF has no ref-model (drafts only).

## The ONE-LINE LAW (owner, round 3 — after tier-2 drift)

Every parable must pass the ONE-LINE TEST: after ONE hearing, the
owner (or a child) can state its core message in one plain
sentence — like: "she spun herself into knots and spun herself out
to freedom." If he has to squint, the parable failed. Names for
parables/seals use REAL-WORD nouns a kid touches (heat-city, the
swept house, the gifts that sank, the heartbeat under everything)
— never liturgical coinages (no "shrine-dust", no "altar of
refusals"). Theological compounds in the layers become kid-nouns in
the telling: sweepings-of-ignorance → the old junk swept out;
sense-goddesses → his own eyes and hands bringing presents;
mātṛkā → the alphabet. Real-world thing first, always.

## TECHNICAL-FIDELITY (Round-5 guard — equal weight to nature-first)
Animals/nature/folk-tale are the go-to register (deha→hive,
spanda→storm, krama→garland) — BUT the creature encodes the
technicals, never evicts them. Every technical member of the work
(counts, loci, stations, named structures, lists) must appear
plainly in the telling OR be named in the hinge-map. Run this
check BEFORE the checklist: if cutting the animal would lose a
doctrine but keeping it costs a term, the term goes in the MAP,
the doctrine stays in the TALE.

## Hard rules
- Machine proposes; owner reviews parable AND image. No render on
  "give me a sample". No receipts invented.
- One Solis base per seal; spent bases never reused (spent-log).
- No tarot correspondences (Skinner's debunk). No Jung default —
  text-internal, contextual only.
- BLOCKED/failed layers: the seal does not proceed (fail-closed).
